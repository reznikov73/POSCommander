# POSCommander

POSCommander — двухпанельный файловый менеджер для Windows, вдохновлённый классическими файловыми менеджерами с двумя панелями.

## Возможности

- Две панели, вкладки, навигация по дискам и папкам.
- Копирование, перемещение, удаление и переименование файлов и папок.
- Перетаскивание между панелями: по умолчанию перемещение на том же диске и копирование между дисками; удерживайте **Ctrl**, чтобы копировать.
- Контекстное меню с просмотром, копированием, перемещением, переименованием, удалением и свойствами файла.
- Работа с ZIP, 7z и другими поддерживаемыми 7-Zip форматами: просмотр содержимого, создание и извлечение архивов.
- Поиск файлов, командная строка с автодополнением и историей.
- Просмотр файлов и отображение системных значков Windows.

## Установка

Скачайте `POSCommander-Setup-<версия>.exe` со страницы [Releases](https://github.com/reznikov73/POSCommander/releases), запустите установщик и выберите папку установки. Установщик создаёт ярлыки в меню «Пуск» и на рабочем столе.

## Разработка

Требуются Windows, Node.js и npm.

```powershell
npm install
npm start
```

Сборка приложения и установщика:

```powershell
npm run build
npm run build:exe
```

`npm run build:exe` создаёт папку `release/build-<дата-времени>/` с распакованным приложением (`win-unpacked/POSCommander.exe`) и полным установщиком NSIS (`POSCommander-Setup-<версия>.exe`). Установщик позволяет выбрать каталог и создаёт ярлыки.

## Основные клавиши

| Клавиша | Действие |
| --- | --- |
| `F3` | Просмотр файла |
| `F4` | Правка файла |
| `F5` | Копирование |
| `F6` | Перемещение |
| `Shift+F6` | Переименование |
| `F7` | Создание папки |
| `F8` | Удаление |
| `Tab` | Переключение между панелями |
| `Ctrl+↑` / `Ctrl+↓` | История командной строки |

В окнах подтверждения стрелки перемещают фокус между кнопками; `Enter` активирует выбранную кнопку, `Esc` закрывает окно или отменяет действие.

## Технологии

Electron, TypeScript, HTML и CSS. Архивы обрабатываются встроенным 7-Zip (`7zip-bin`).
